# Site da Cozinha 48

Site oficial: estúdio de lives e gravações de DJ sets dentro de uma cozinha.

## Arquivos
- `index.html` — página principal do site
- `conta.html` — área de conta dos fãs e painel dos donos (usa Supabase)
- `logo.png` — logomarca
- `lowix.jpg` — foto de artista (carrossel)
- `supabase-setup.sql` — script do banco de dados (referência; já foi executado)

## Como o site é publicado
Os arquivos deste repositório são publicados automaticamente pelo Netlify
no domínio cozinha48.com. Qualquer alteração enviada aqui vai pro ar sozinha.
